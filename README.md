# HanziFlow
This offline web application allows you to import Chinese vocabulary lists from `.xlsx` files containing Hanzi, Pinyin, and English meanings. Test your vocabulary knowledge, track your learning progress, monitor your accuracy, and review incorrectly answered words to strengthen your Chinese vocabulary.

Download the .zip file, from the packages. Extract it and keep everything in a single folder.

Just import your Chinese vocabulary list which must be in `.xlsx` format, and must include separate columns for Hanzi, Pinyin and English meaning. I believe you can do the rest.

You can import as many words as you want.

Happy learning!!
